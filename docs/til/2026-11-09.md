# TIL 2026-11-09 (월) · #2 프로젝트 초기 구조

**Why** — 테스트가 설치된 패키지가 아니라 로컬 폴더를 import하면, 배포한 뒤에야 터지는 import 오류를 놓칠 수 있다. 이걸 미리 막고 싶었다.

**What** — `src/` 레이아웃과 `pip install -e .`를 함께 쓰면 테스트도 설치된 패키지 경로로 import한다.

**How**
```toml
# pyproject.toml
[build-system]
requires = ["hatchling"]
build-backend = "hatchling.build"

[project]
name = "stats_toolkit"
dependencies = ["numpy", "pandas", "scipy"]
```
```bash
pip install -e ".[dev]"
python -c "import stats_toolkit; print(stats_toolkit.__file__)"  # src/ 경로가 찍히면 성공
```
