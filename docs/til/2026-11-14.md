# TIL 2026-11-14 (토) · #6 단위 테스트

**Why** — 실수 계산 결과를 `==`로 비교했더니 테스트가 실패했다. 컴퓨터에서는 `0.1 + 0.2 != 0.3`이기 때문이다.

**What**
- 실수는 `pytest.approx`로 허용 오차 안에서 비교한다.
- `NaN == NaN`은 항상 `False`다. 그래서 `math.isnan`으로 확인해야 한다.
- `@pytest.mark.parametrize`를 쓰면 경계 케이스를 표 하나에 모을 수 있다.

**How**
```python
@pytest.mark.parametrize("data, expected", [
    ([1, 2, 3, 4], 1.6667),
    ([5], float("nan")),   # 원소 1개 → 표본분산 정의 불가
])
def test_variance(data, expected):
    result = variance(data)
    if math.isnan(expected):
        assert math.isnan(result)
    else:
        assert result == pytest.approx(expected, rel=1e-3)
```
