# TIL 2026-11-13 (금) · #5 기술통계

**Why** — 같은 데이터인데 `np.var`와 `pandas.var`의 결과가 달랐다.

**What** — 두 라이브러리의 `ddof` 기본값이 다르다.
- numpy는 `ddof=0`이다. n으로 나누는 모집단 분산을 계산한다.
- pandas는 `ddof=1`이다. n-1로 나누는 표본 분산을 계산한다.
- 이 차이를 조사하다가 **#7 버그**를 발견했다.

**How**
```python
import numpy as np, pandas as pd
x = [1, 2, 3, 4]
np.var(x)           # 1.25   (n으로 나눔)
pd.Series(x).var()  # 1.6667 (n-1로 나눔)
np.var(x, ddof=1)   # 1.6667
```
→ 앞으로 우리 함수에서는 `ddof`를 기본값에 맡기지 않고 항상 명시한다.
