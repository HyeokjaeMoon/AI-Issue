# TIL 2026-11-16 (월) · #8 t-검정

**Why** — 두 그룹의 분산이 다른데 Student t-검정을 쓰면 p-value가 왜곡된다.

**What**
- `scipy.stats.ttest_ind`의 기본값은 `equal_var=True`로, 분산이 같다고 가정하는 Student t-검정이다.
- 그래서 분산이 같다고 가정하지 않는 **Welch t-검정**(`equal_var=False`)을 우리 함수의 기본값으로 정했다.

**How**
```python
from scipy import stats

def ttest_independent(a, b, alpha=0.05, equal_var=False):
    res = stats.ttest_ind(a, b, equal_var=equal_var)
    return TestResult(statistic=res.statistic, pvalue=res.pvalue,
                      reject=res.pvalue < alpha)
```
