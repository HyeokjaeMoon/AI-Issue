# TIL 2026-11-10 (화) · #2 CI 설정

**Why** — 로컬(Windows)에서는 통과하는데 다른 환경에서 실패하는 문제를 PR 단계에서 잡고 싶었다.

**What** — GitHub Actions의 `matrix`를 쓰면 OS와 파이썬 버전 조합을 한 번에 테스트할 수 있다. 린트(ruff)는 테스트보다 먼저 돌려서 문제가 있으면 빨리 실패하게 한다.

**How**
```yaml
strategy:
  matrix:
    os: [ubuntu-latest, windows-latest]
    python-version: ["3.11", "3.12"]
steps:
  - uses: actions/setup-python@v5
    with: { python-version: "${{ matrix.python-version }}" }
  - run: pip install -e ".[dev]"
  - run: ruff check .
  - run: pytest
```
