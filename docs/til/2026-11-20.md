# TIL 2026-11-20 (금) · #10 시각화

**Why** — 그래프의 한글이 □로 깨졌다. CI에서는 화면이 없어서 matplotlib가 실패했다.

**What**
- 한글 폰트를 지정하고, 마이너스 기호가 깨지지 않도록 `axes.unicode_minus`를 끈다.
- 화면이 없는 환경(CI)에서는 `Agg` 백엔드를 쓴다.
- Ubuntu 러너에는 기본 한글 폰트가 없어서 `fonts-nanum`을 설치한다.

**How**
```python
import matplotlib
matplotlib.rcParams["font.family"] = ["Malgun Gothic", "NanumGothic"]
matplotlib.rcParams["axes.unicode_minus"] = False

fig.savefig(path, dpi=150, bbox_inches="tight")
```
```yaml
env: { MPLBACKEND: Agg }
- run: sudo apt-get install -y fonts-nanum   # ubuntu 러너만
```
