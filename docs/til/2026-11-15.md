**Why** — 1주차 마감일(11/13)까지 #7을 끝내지 못해서 주말에 마무리했다.

**What**
- 버그를 고칠 때는 **버그를 재현하는 테스트를 먼저** 쓰고 실패하는 것을 확인한다. 코드는 그다음에 고친다.
- `scipy.stats.skew`와 `kurtosis`도 기본값이 `bias=True`(편향 추정)다. 분산의 `ddof`와 같은 종류의 함정이다.

**How**
```python
def test_variance_default_is_sample():      # 1) 실패하는 테스트 먼저
    assert variance([1, 2, 3, 4]) == pytest.approx(1.6667, rel=1e-3)

def variance(data, population=False):        # 2) 수정
    return float(np.var(data, ddof=0 if population else 1))
```
