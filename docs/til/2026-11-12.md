# TIL 2026-11-12 (목) · #4 결측치·이상치

**Why** — 결측치를 평균으로 채웠더니, 이상치 하나 때문에 채워 넣은 값이 크게 치우쳤다.

**What**
- 분포가 한쪽으로 치우쳐 있으면 평균보다 **중앙값으로 채우는 쪽**이 안전하다.
- IQR 방식은 분포에 대한 가정이 없지만, Z-score 방식은 정규분포를 가정한다.

**How**
```python
df.isna().mean()                      # 컬럼별 결측 비율
df["x"] = df["x"].fillna(df["x"].median())

q1, q3 = df["x"].quantile([0.25, 0.75])
iqr = q3 - q1
outlier = (df["x"] < q1 - 1.5 * iqr) | (df["x"] > q3 + 1.5 * iqr)
```
