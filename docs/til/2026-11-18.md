# TIL 2026-11-18 (수) · #9 선형회귀 (추정)

**Why** — 교과서 공식 `(XᵀX)⁻¹Xᵀy`를 그대로 구현했더니, 서로 상관이 높은 변수가 있을 때 계수가 크게 흔들렸다.

**What**
- 역행렬을 직접 구하면 수치적으로 불안정하다. 내부적으로 SVD를 쓰는 `np.linalg.lstsq`가 더 안전하다.
- 조건수(`np.linalg.cond`)가 크면 다중공선성을 의심한다.

**How**
```python
X = np.column_stack([np.ones(len(x)), x])     # 절편 열 추가
beta, *_ = np.linalg.lstsq(X, y, rcond=None)
if np.linalg.cond(X) > 1e3:
    warnings.warn("다중공선성 가능성이 있습니다")
```
