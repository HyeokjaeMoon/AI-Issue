# TIL 2026-11-19 (목) · #9 선형회귀 (평가)

**Why** — 변수를 추가할수록 R²가 무조건 올라가서, R²로는 모델을 비교할 수 없었다.

**What**
- **조정 R²**는 변수 개수(p)만큼 불이익을 준다: `1 - (1-R²)(n-1)/(n-p-1)`
- 직접 구현한 값이 맞는지 확인하려고 `statsmodels.OLS` 결과와 비교하는 테스트를 만들었다.
- 잔차가 정규분포를 따르는지는 `stats.shapiro`로 확인한다. 다만 표본(n)이 크면 아주 작은 차이도 유의하게 나온다.

**How**
```python
r2 = 1 - ((y - y_hat) ** 2).sum() / ((y - y.mean()) ** 2).sum()
adj_r2 = 1 - (1 - r2) * (n - 1) / (n - p - 1)

ref = sm.OLS(y, sm.add_constant(x)).fit()
assert adj_r2 == pytest.approx(ref.rsquared_adj)
```
