# TIL 2026-11-17 (화) · #8 카이제곱 검정

**Why** — 표본이 작은 교차표에서도 카이제곱 p-value를 믿어도 되는지 확인해야 했다.

**What**
- 기대빈도가 5 미만인 칸이 있으면 카이제곱 근사가 부정확하다. 2×2 표라면 **Fisher 정확검정**을 쓴다.
- `chi2_contingency`는 자유도가 1이면 Yates 보정(`correction=True`)을 기본으로 적용한다.
- 모든 검정 함수가 같은 형태로 결과를 돌려주도록 결과를 `dataclass`로 묶었다.

**How**
```python
chi2, p, dof, expected = stats.chi2_contingency(table)
if (expected < 5).any() and table.shape == (2, 2):
    _, p = stats.fisher_exact(table)

@dataclass(frozen=True)
class TestResult:
    statistic: float
    pvalue: float
    reject: bool
```
