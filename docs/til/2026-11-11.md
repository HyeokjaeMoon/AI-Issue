# TIL 2026-11-11 (수) · #3 데이터 로더

**Why** — 공공데이터 CSV를 열자 `UnicodeDecodeError`가 났다. 국내 데이터는 cp949(EUC-KR 확장)로 저장된 경우가 많다.

**What**
- 확장자는 `Path.suffix`로 판별한다.
- 인코딩은 utf-8을 먼저 시도하고, 실패하면 cp949로 다시 읽는다.
- `read_excel`을 쓰려면 `openpyxl`을 따로 설치해야 한다.

**How**
```python
def load_data(path, encoding=None):
    path = Path(path)
    if path.suffix == ".csv":
        for enc in [encoding] if encoding else ["utf-8", "cp949"]:
            try:
                return pd.read_csv(path, encoding=enc)
            except UnicodeDecodeError:
                continue
        raise ValueError(f"인코딩을 판별할 수 없습니다: {path}")
    if path.suffix in {".xlsx", ".xls"}:
        return pd.read_excel(path)
    raise ValueError(f"지원하지 않는 형식: {path.suffix}")
```
